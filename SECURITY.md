# Security

To report a vulnerability, [open an issue](https://github.com/equinoxaifinance-rgb/fluxproof-agent-card/issues) that says only that you have a security report, with no details. We will reply there with a private way to send the affected route, impact, and reproduction. Never post credentials, API keys, card data, or personal information in an issue.

This repository contains no product engine or deployable commercial source. Report service issues against the live product URL.
